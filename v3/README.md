# Application workspace

The Svelte 5/SvelteKit frontend, FastAPI backend and Electron desktop shell live here. See the [repository README](../README.md) for installation and startup.

- `apps/frontend`: chat, prompts, simulation controls and trigger settings.
- `apps/desktop-electron`: native window and file dialogs.
- `services/python-api`: persistence, Claude CLI integration, TCP control and trigger runtime.
- `scripts`: development launchers and their regression checks.
- `packages/shared-contracts`: reserved contract workspace.
